# 透明 SPICE · 电路分析教学台

一个免费的电路分析教学软件。可以直接在浏览器中使用，也提供 Windows 免安装下载包；不要求普通用户运行安装程序。

## 下载与安装（Windows）

1. 打开本项目 GitHub 仓库的 **Releases** 页面，下载 `透明SPICE-免安装版.zip`。
2. 在 Windows 中右键 ZIP 并选择“全部解压”。
3. 打开解压后的文件夹，双击 `index.html` 即可运行，无需安装、管理员权限或联网。

也可以选择下载 `透明SPICE-Setup.exe`，由安装程序创建桌面和开始菜单快捷方式。软件免费使用，采用 MIT 开源许可证。新版本发布后，重新下载并解压免安装版即可更新。

## 手机浏览器访问

本项目也可以作为网页在手机上打开，页面会根据窄屏调整布局。仓库启用 GitHub Pages 后，`.github/workflows/pages.yml` 会在更新 `main` 分支时自动部署。首次发布时，请在仓库 **Settings → Pages** 将构建来源设为 **GitHub Actions**；完成后可用 `https://<用户名>.github.io/<仓库名>/` 访问，也可以在手机浏览器中选择“添加到主屏幕”。

> Windows 可能会对未进行代码签名的安装包显示安全提示。请只从本项目 GitHub Releases 下载，并在下载页核对发布者提供的 SHA-256 校验值。当前版本尚未配置代码签名证书。

## 当前实现

- 可在空白画布上自由放置 R、C、L、独立电压源、独立电流源和开关，再用导线连接元件端子。
- 可添加分支接点、移动元件和 GND 接点，并以 90° 步进旋转器件；下方元件表可编辑数值、状态和删除元件。GND 仍作为参考节点 `0`。
- 直流工作点分析：电容开路，电感和闭合开关按理想短路处理。
- 单频交流相量分析：电容、电感按复导纳建模，独立源按峰值、0° 相位处理；结果显示幅值、相位及节点电压波形。
- 使用改进节点法组装 MNA 矩阵，并用带部分主元的高斯消元求解。
- 展示矩阵方程、节点电压、电压源电流、电阻电流和元件级推导说明。
- 元件值支持基础 SI 后缀，例如 `1k`、`10u`、`2m`；大数可用科学计数法，例如 `1e6`。

## 操作

1. 选择器件并填写参数，点击一次“放元件”，再点击画布空白处放置一个器件。放置后自动切换到移动模式，可直接拖动该器件；要继续添加器件，再点击一次“放元件”。
2. 选择“导线”后，在画布选择“导线”后点击起点、转角和端点，导线会自动修正为横平竖直的折线；点击端子即可连接；导线端点接触另一段导线时会自动创建接点。双击空白处以未连接端点结束。也可按住拖动画线。按 Esc 取消。
3. 选择“旋转器件”后点击器件，每次旋转 90°；选择“移动”后可拖动器件或 GND 接点。
3. 元件左端为端子 a；电压源 a 端为正，电流源方向为 a → b。开关状态可在元件表中切换。
4. 点击“运行分析”查看结果；“删除器件”工具可点击删除画布上的元件，并一并清理其端子导线；元件表也提供“删除”按钮。接错导线可点击“撤销导线”。打开软件时画布为空白；点击“恢复示例”可载入 12 V 电源驱动的电阻分压电路。

放置前先输入纯数字，再从旁边的单位菜单选择单位。R 可选 Ω、kΩ、MΩ；C 可选 F、mF、μF、nF、pF；L 可选 H、mH、μH；V 可选 V、mV、kV；I 可选 A、mA、μA。S 选择初始通/断状态。缺少参数或输入无效时不会放置器件。

## 开发与部署

本项目是纯静态网站，不需要构建步骤或第三方依赖。GitHub Pages 可直接从仓库根目录发布；也可以部署到其他支持静态文件托管的平台。桌面和手机浏览器均可访问。

Windows 免安装版和桌面安装包由 GitHub Actions 在发布版本标签（例如 `v1.0.0`）时自动构建，并附加到 GitHub Release，同时生成 SHA-256 校验文件。手机网页则由 Pages 工作流从 `main` 分支自动部署。重建安装包请在 Windows 上运行 `powershell -ExecutionPolicy Bypass -File installer/build-installer.ps1`。

## 范围

当前实现直流工作点与单频交流相量分析。暂态分析、符号解，以及网孔法/节点电压法独立求解器尚未实现；方法标签用于教学说明，当前数值求解统一采用 MNA。交流源相位暂按 0°。目标定位为课程演示原型，不替代成熟 SPICE 工具。
